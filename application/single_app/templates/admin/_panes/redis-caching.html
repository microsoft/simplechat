Conversation Cache

Cache conversation list, feed, and advanced-search results per user. Redis is optional; cache misses and disabled cache paths continue using source Cosmos queries.

When enabled, list/feed/search payloads are cached by user and version. Disabling this bypasses cache reads and writes without requiring Redis.
Default 120 seconds. User-scoped version invalidation refreshes changed conversations; set to 0 to skip writing new entries.

Request & Stream Timeouts

Bound upstream AI model read waits, multi-window document action duration, and disconnected stream retention so stalled requests cannot tie up worker threads.

Worker capacity guidance: Each active chat stream holds one web worker HTTP thread and one dedicated chat-stream worker thread until it finishes, times out, or disconnects. Keeping per-chunk read timeouts, total document action deadlines, and disconnect grace windows bounded prevents stalled upstream model calls from exhausting worker threads.
{{ settings.model_stream_read_timeout_seconds | default(120) }} sec
30 sec 600 sec
Maximum wait for the first token from an AI model or between streamed chunks before the socket read fails. Active streams that keep emitting tokens are not interrupted by this timeout.
{{ settings.document_action_timeout_seconds | default(300) }} sec
60 sec 900 sec
Overall wall-clock budget for synchronous and multi-window document actions (Analyze and Compare). Completed durable window checkpoints are preserved if a run stops at this deadline so a retry can resume.
{{ settings.stream_disconnect_grace_seconds | default(60) }} sec
0 sec 300 sec
How long an in-flight stream continues running after the browser disconnects so a page refresh or brief network drop can reattach. If no client reattaches before this window expires, the stream cancels itself and frees its worker thread. Set 0 to cancel immediately on disconnect.
{{ settings.model_call_max_retries | default(1) }} retries
0 retries 3 retries
Maximum automatic SDK retries per model call on transient connection or rate-limit errors. Lower values release worker threads faster when an upstream model endpoint is degraded.
