Personal File Sync App Role Setup

Create the personal File Sync app role on the SimpleChat app registration, then assign users or groups to the role in the Enterprise App before enabling the personal require-role toggle.

Capability App role value Typical assignment
Personal File Sync PersonalFileSyncUser Users allowed to manage personal sync sources
  1. Open Microsoft Entra admin center and edit the SimpleChat app registration.
  2. Add the app role with allowed member type Users/Groups and value exactly matching the table.
  3. Open the Enterprise App for SimpleChat and assign users or groups to the app role.
  4. Have affected users sign out and sign back in so their role claims refresh.
