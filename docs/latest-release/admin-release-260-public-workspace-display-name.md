Current release version for Custom Public Workspace Display Name: **0.261.001**

The optional display name can replace Public Workspace with tenant language such as Domain Knowledge across navigation, Profile, chat scope selection, and directory pages. End users see the custom label throughout the interface while internal workspace identifiers remain unchanged.

## Why It Matters

This matters because admins can align shared knowledge areas with organizational terminology without data migration.

## How to Try It

1. Open Admin Settings > Workspaces and set the tenant-specific Public Workspace display name.
2. Choose a short label that users will recognize in navigation, Profile, chat scope selection, and directories.
3. Confirm help documentation and support scripts use the same display name users will see.
4. Leave the field empty if the tenant should continue using the default Public Workspace wording.

## Where to Find It

- **Open Workspaces** &mdash; Set the custom Public Workspace display name.
