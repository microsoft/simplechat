Current release version for See Which Sources Were Actually Used: **0.261.001**

Complete document and web retrieval results are kept separate from the exact references used in the final response. Used documents follows the cited responses, conversation details marks which items were cited within the full inventory, and conversation and message exports leave out sources that were retrieved but never referenced. Long lists show the first 25 sources with a control to reveal the rest, and inline image and video galleries render only the media the answer actually cited.

## Why It Matters

This matters because a search that returns sixty chunks used to make it impossible to tell which three actually shaped the answer you are reading.

## How to Try It

1. Open Chat and ask a question grounded on a workspace with many documents.
2. Expand the Sources disclosure and note the full set of retrieved results.
3. If more than 25 are listed, use the control to show the remaining sources.
4. Open the Used documents drawer and compare it against the full Sources list.
5. Open conversation details and look for the markers on items that were cited.
6. Export the conversation and confirm retrieved-only sources are not included.
7. Ask a question in a workspace containing images and confirm only cited media appears inline.

## Where to Find It

- **Open Chat** &mdash; Compare the full Sources list against the Used documents drawer.
