## Admin Setup and User View

Admins control whether Latest Features are visible from the Support menu and can choose which current-release cards are shared with end users. Turn the destination on with **Enable Latest Features Destination** under **Admin Settings > Help > Support Menu**, then review the cards end users will see under **Admin Settings > Help > User-Facing Latest Features**.

Users see the curated set from **Support > Latest Features**. The guides below use the same screenshots as the in-app gallery. Two tiers are published here: the user-facing v0.261.001 set, and an admin-managed set covering the tenant controls behind those capabilities.
