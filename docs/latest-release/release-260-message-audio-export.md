Current release version for Download a Response as Audio: **0.260.001**

The export uses the active Azure Speech voice and speed settings for your environment and produces a normal MP3 download. The audio is generated on demand and is not stored in SimpleChat, so nothing is retained after the download completes.

## User Side

Any completed chat message can be exported as an MP3 using the configured speech voice and speed.

## Admin Side

Admins decide whether Download a Response as Audio is available in your environment. If you cannot find Open Chat, ask whether the related settings, governance policy, or workspace access has been enabled for your account.

## Why It Matters

This matters because a long answer is sometimes easier to absorb on a commute than on a screen.

## How to Try It

1. Open Chat and find a completed assistant response you want to listen to.
2. Open the message actions for that response.
3. Choose the option to export the message as audio.
4. Wait for the MP3 to be generated from the configured speech voice.
5. Save the downloaded file when your browser prompts you.
6. Play it back in any normal audio player.
7. Repeat on another message and note that nothing is stored in SimpleChat between exports.
