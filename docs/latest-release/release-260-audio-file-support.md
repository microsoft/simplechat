Current release version for Upload Almost Any Audio File: **0.261.001**

Media handling is now bundled directly into SimpleChat container builds, which greatly expands the audio formats it can recognize and transcribe. Transcription degrades gracefully when the media tooling is unavailable rather than failing outright, and iPhone M4A voice memo uploads work correctly.

## User Side

Audio uploads now cover a much wider set of formats including AAC, FLAC, M4A, OGG, Opus, WAV, WebM audio, and WMA.

## Admin Side

Admins decide whether Upload Almost Any Audio File is available in your environment. If you cannot find Open Personal Workspace and Open Chat, ask whether the related settings, governance policy, or workspace access has been enabled for your account.

## Why It Matters

This matters because meeting recordings and voice memos arrive in whatever format the recording device produced, and converting them by hand first was a real obstacle.

## How to Try It

1. Open Personal Workspace and go to the Documents section.
2. Upload an audio file in whatever format you have, such as an iPhone M4A voice memo or a WAV recording.
3. Wait for the file to finish processing and produce a transcript.
4. Open the document details and read the transcript that was generated.
5. Open Chat and ground a conversation on that audio file.
6. Ask for a summary, decisions, or action items from the recording.
7. Check the returned citation to confirm it points back at the audio document.
