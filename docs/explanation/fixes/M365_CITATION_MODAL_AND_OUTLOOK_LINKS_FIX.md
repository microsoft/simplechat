# Microsoft 365 Citation Modal and Outlook Links Fix (v0.261.305)

Fixed in version: **0.261.305**.
`application/single_app/config.py` advances from **0.261.304** to **0.261.305**.

## Issue

Microsoft 365 citation chips and SharePoint links worked, but the source popup's
action text could disappear against its background. Email and calendar recalls
could lose the metadata needed to open the specific item in Outlook on the web.
Answers also used unnecessary introductions such as "Confirmed from the
SharePoint document" even though the citation identified the source.

## Root cause

The V2 source popup lived inside the answer's Markdown subtree. Descendant link
styling could override the action's foreground with the same accent used for its
background. A production-CSS regression reproduced **1.00:1** action contrast in
light mode; the old browser tests did not load that stylesheet.

Custom Graph `select_fields` replaced baseline mail/calendar fields, including
`webLink`. Calendar keyword cleanup could also remove fields introduced for
scanning that were needed for citation identity or source-card details.

The unwanted prose was generated by the model, not a hardcoded UI label.
Citation-copy instructions did not include shared guidance for answering directly
without routine source-provenance introductions.

## Technical changes

| File | Change |
| --- | --- |
| `semantic_kernel_plugins/msgraph_plugin.py` | Merges baseline mail/calendar citation fields into custom selections. Calendar scan-only additions are tracked separately, so cleanup preserves baseline and caller-requested fields. |
| `functions_m365_citations.py` | Adds shared, Microsoft 365-scoped direct-answer guidance to tool citation instructions and orchestration source notes, retaining the sources-note heading and marker grammar. |
| `functions_orchestration_composition.py`, `functions_mixed_source_orchestration.py` | Carries the same guidance into trusted composition and mixed-source handoffs without weakening citations or coverage disclosures. |
| `v2_ui/src/components/chat/M365CitationChip.tsx` | Reuses the shared portaled `Modal`, isolating the card from Markdown styles and providing focus containment, Escape/backdrop dismissal and focus restoration. Uses readable local theme tokens and explains unavailable links. |
| `v2_ui/src/components/chat/ConversationDrawer.tsx`, `MessageInspector.tsx` | Uses **Open in Outlook** for email/calendar items and retains **Open online** for files, with readable link colors in both themes. |
| `functional_tests/test_m365_source_citations.py`, `test_m365_mail_calendar_search.py` | Exercises real plugin code with selection-aware Graph responses, pagination/continuation and prompt propagation. |
| `ui_tests/test_v2_m365_source_citations.py`, `ui_tests/fixtures/color_contrast.py`, `test_v2_workflow_change_tracking.py` | Loads production CSS and shares the existing composited-color contrast measurement instead of duplicating it. Covers themes, phone/desktop layouts, keyboard behavior, literal metadata, unavailable URLs and exact Outlook destinations. |

Only validated HTTPS URLs supplied by Microsoft Graph become links. The shared
link component retains `target="_blank"` and `rel="noopener noreferrer"`.
No Graph lookup, additional permission, route, container or history migration is
introduced.

## Reader behavior

Click a citation chip to inspect its saved source details. **Open in Outlook**
opens the recalled email or calendar event in a new tab; the same action is
available in **Documents** and the reply's **Sources** panel. SharePoint and
OneDrive destinations are unchanged.

Existing messages and citation records remain untouched. A saved record without
a safe online URL shows an unavailable-link explanation instead of a fabricated
or dead link. Ask for the item again to capture current details and a Graph URL
if available.

The model is instructed to answer directly. Source names remain appropriate when
the user asks about provenance or when distinguishing conflicting evidence.
Uncertainty, missing evidence and partial coverage must still be disclosed.
Meeting locations, organizers, numbered layouts and citation markers are kept.
No client-side phrase stripping is performed.

## Validation

The targeted functional suite passed **59 tests**. The browser citation suite
and the existing workflow contrast consumers passed **17 tests**, with **23**
unrelated workflow tests deselected. The V2 TypeScript/production build and the
three modified components' XSS sink checks passed.

```powershell
python -m pytest .\functional_tests\test_m365_source_citations.py .\functional_tests\test_m365_mail_calendar_search.py -q
npm --prefix .\application\v2_ui run build
$env:PLAYWRIGHT_SERVICE_URL = ''
$env:PYTHONPATH = "$($PWD.Path)\ui_tests\fixtures"
python -m pytest .\ui_tests\test_v2_m365_source_citations.py .\ui_tests\test_v2_workflow_change_tracking.py -k "m365_source_citations or classic_edits_show_author_previous_value_revert_and_item_rows" -q
python .\scripts\check_xss_sinks.py --full-file .\application\v2_ui\src\components\chat\M365CitationChip.tsx .\application\v2_ui\src\components\chat\ConversationDrawer.tsx .\application\v2_ui\src\components\chat\MessageInspector.tsx
```

Production-CSS checks require at least **4.5:1** source text/action contrast.
Final email-card captures measured a minimum of **5.66:1** in light mode and
**7.54:1** in dark mode, at both **1440 x 900** and **390 x 844**. File and
calendar cards are covered by the same themed browser checks. Sidebar and Sources
actions are also measured, and intercepted Outlook pages verify the exact item
URL and new-tab behavior without accessing a real mailbox.

The broader `test_mixed_source_manifest_contracts.py` suite has **9 existing
failures and 6 passes** in this environment. The same failures reproduce with
the unchanged `HEAD` orchestration module and live network access blocked:
legacy authorization fixtures cannot resolve some sources, and authentication
paths lack Cosmos credentials. Those unrelated fixtures and access controls are
not changed by this fix. Prompt tests validate propagation, not deterministic
wording from a live model.
